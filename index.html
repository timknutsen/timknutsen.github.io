I'm a geneticist from Ås, Norway. I like building things with code and AI, and this is where I keep them.

About

I work with genetic data, and I write software to make sense of it.

I worked five years as a bioengineer in a hospital laboratory, then went back to university. I took an MSc in biology and a PhD in statistical genomics at NMBU. My thesis mapped the genes behind milk fat composition in cattle.

Away from the computer I train, and I forage mushrooms around Ås. I have built a small app for each.

AI

AI has changed how I build things.

I use coding agents every day. Projects that used to stop at an idea, like a small web app or a data pipeline, now get finished. The agent writes much of the code. I decide what to build, check the results, and know the data well enough to see when something is wrong. That last part still matters most.

  • Coding agents

    Writing and reviewing code for research pipelines and small apps.

  • Language models for data

    Pulling structured data out of messy text and documents.

  • MCP servers

    Connecting language models to databases and tools, so they look things up instead of guessing.

  • Computer vision

    Measuring traits from images, so more animals can be recorded at lower cost.

  • Deep learning in genomics

    Predicting the effect of genetic variants from DNA sequence. I am a co-author on a 2025 paper on this.

  • Small apps

    Web apps for my own use, hosted on this domain. Two of them are below.

Projects

Things I have built, from GitHub and this domain. Some are apps I use myself, some are research pipelines.

  • soppkart

    An interactive map of likely mushroom habitat around Ås, built from public map layers. It logs my own finds and empty searches, so the model improves as I use it.

  • treningsapp

    A training-plan web app for the phone. Strength on Saturday, running on Sunday, and missed sessions move automatically.

  • wgs-align-varcall

    Slurm and GATK pipelines for whole-genome alignment and short-variant calling. One site config makes it portable across HPC clusters.

  • beagle_impute

    Chromosome-wise genotype imputation with Beagle or AlphaImpute2, run through Snakemake.
