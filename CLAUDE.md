# CLAUDE.md

Personal website for Tim Martin Knutsen. Plain static site on GitHub Pages:
`index.html` + `styles.css`, no build step. Pushing to `main` deploys.

Before editing, read `WEBSITE_IDEAS.md`. It holds the working rules, the
public source baseline, the idea backlog, and the decision/commit log.

Rules:
- Every public claim must trace to a public source, publication, or commit.
- Plain scientist voice. No marketing language. Never use em dashes.
- Keep `publications.json` in sync with the publication list in `index.html`.
- Update the footer "Last updated" line when content changes.
- After committing, log the commit in `WEBSITE_IDEAS.md`.
- Preview locally with `python3 -m http.server 8000`.
